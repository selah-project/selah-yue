# 希伯來聖經(塔納赫)— 粵語譯本

希伯來聖經(塔納赫)譯做粵語 — 逐節逐節、逐字逐字,
每個希伯來字下面都有粵語解釋。

呢個係 Selah 工程嘅**第六十八張櫈** — 第一張粵語櫈,
成個階梯第一張寫「講嘅話」嘅漢字櫈。倉庫:`selah-yue`。

## 希伯來文行先

呢個譯本係為咗帶你去到希伯來原文 — 唔係取代佢。
你讀嘅係希伯來文:啲字母、啲讀音、啲記號。
下面嗰行粵語係一扇窗,唔係替身。
兩者若有出入,以希伯來文為準。

## 呢個譯本唔係乜嘢

- **唔係你本聖經嘅替代品。** 留住你本聖經,讀佢,
  同佢祈禱。呢份工作企喺旁邊 — 指向希伯來原文。
- **唔係教義。** 淨係原文,逐字逐字,每一節都查證得到。

睇 `NOTES.md` 有封印記錄,`manifest.edn` 有承傳世系。
